## 1. 已落本地的外部参考

### 房地产 / site appraisal 结构参考

1. [Hometrack_Site_Appraisal_Report_Sample.pdf](/Users/wuchenghan/Documents/New%20project%202/docs/references/source_pdfs/Hometrack_Site_Appraisal_Report_Sample.pdf)
   
   最值得借的不是数字，而是页序和叙事：
   - 先给 summary
   - 再讲 site / catchment

   - 最后收束到评论和判断
   
   对应到我们：
   - `项目概览 / 初步判断`
   - `站点介绍 & 区域范围`
   - `主要充电竞争对手地图`
   - `observed usage / demand proxy`
   - `风险与下一步`

### EV charging site screening / utilisation 参考

2. [UKPN_Charge_Collective_Final_Report.pdf](/Users/wuchenghan/Documents/New%20project%202/docs/references/source_pdfs/UKPN_Charge_Collective_Final_Report.pdf)
   
   这份最有用的是方法逻辑，不是版式：
   - location
   - utilisation
   - charging event / charging need
   - grid / delivery constraints
   
   对应到我们：
   - 不只看“附近有桩”
   - 要看“附近这些桩是不是真的有人用”
   - 再把 observed demand 和新站 capture 分开

3. [IET_Guide_to_EV_Charging_Infrastructure_for_Local_Authorities.pdf](/Users/wuchenghan/Documents/New%20project%202/docs/references/source_pdfs/IET_Guide_to_EV_Charging_Infrastructure_for_Local_Authorities.pdf)
   
   这份适合借：
   - site selection 维度
   - 充电场景分类
   - charger type 和 dwell time 的匹配
   - 部署和运营时常见约束
   
   对应到我们：
   - `这个站点是什么场景`
   - `它更像 destination / retail / route-adjacent / mixed-use`
   - `周边 observed usage 跟场景是否匹配`

4. [Pod_Point_Savills_Case_Study.pdf](/Users/wuchenghan/Documents/New%20project%202/docs/references/source_pdfs/Pod_Point_Savills_Case_Study.pdf)
   
   这份是商业地产视角的 EV 案例，适合借：
   - 物业 / 场地方关心什么
   - dwell time、客流、可见性、易找易用
   - usage reporting 对地主/业主的意义
   
   对应到我们：
   - 为什么 Stage-0 不能只讲技术
   - 为什么要讲场站类型、停留场景、周边业态

## 4. 对我们最有用的 PPT 逻辑

按现在的 Stage-0 目标，最该借的是下面这套组合：

1. `Hometrack`
   
   借页序：summary -> site -> comparables -> conclusion

2. `UKPN Charge Collective`
   
   借证据逻辑：location + utilisation + demand signal

3. `IET guide`
   
   借场景语言：site type、dwell time、charger fit

4. `Pod Point × Savills`
   
   借物业/地主视角：停留、可见性、体验、使用报告

5. `CRA × Hubject`
   
   只借视觉纪律：黑标题、蓝色 subsection、留白、标准 caption

## 5. 建议的 Stage-0 deck 骨架

建议先固定成 6 页：

1. `项目概览 / 初步判断`
2. `站点介绍 & 区域范围`
3. `主要充电竞争对手地图`
4. `真实使用情况`
5. `充电时间规律 & 初步需求量级`
6. `主要风险 / 待验证事项 / 下一步`

这 6 页里，最核心的是第 3-5 页。

## 6. 不要照搬的东西

下面这些是参考里常见，但不应该直接搬进当前 Stage-0 的：

- 过早的 investment recommendation 语气
- 过细的 CAPEX / IRR / payback
- 把区域 observed demand 直接翻成新站收入
- 过重的宏观人口 / household / car parc 叙事
- 过多彩色装饰和 traffic-light 图形
